# Chat-Analyzer 🤖
Сервер для анализа чатов с использованием AI, векторной базы данных [Qdrant](https://qdrant.tech/) и асинхронных воркеров.

## 🌟 Ключевые особенности
- **Семантический поиск** — поиск по смыслу, а не только по точным совпадениям.
- **Управление контекстом** — система учитывает историю сообщений.
- **Фоновая обработка** — воркеры выполняют ресурсоёмкие задачи.
- **Telegram‑интеграция** — удобный бот для пользователей.

## 🛠 Технологический стек
- **Язык:** [Python 3.10–3.12](https://www.python.org/)
- **База данных:** [Qdrant](https://qdrant.tech/)
- **AI‑компоненты:** API запросы к сервисам
- **Интерфейс:** [Telegram Bot API](https://core.telegram.org/bots/api)
- **Архитектура:** Асинхронные воркеры и модульная структура

## 📂 Структура проекта
- **src/** — Основной код
  - **main.py** — Точка входа, инициализация сервисов и воркеров.
  - **config.py** — Централизованное хранение конфигураций.
  - **modules/** — Модульные блоки:
    - **ai/** — Логика нейросетей (промпты, поиск).
    - **message/** — Обработка сообщений (бот, история, структура).
    - **telegram/** — Работа с Telegram API (обработчики, декораторы).
    - **qdrant/** — Взаимодействие с векторным хранилищем.
    - **workers/** — Фоновые процессы для сообщений и векторов.
    - **utils.py** — Общие вспомогательные функции.
  - **services/** — Высокоуровневые сервисы:
    - **ai.py**, **qdrant.py**, **parser.py**, **telegram.py**.

## 📦 Установка и запуск
0. #### **!! Для запуска проекта вам необходимо иметь [Docker](https://docs.docker.com/engine/install/) !!**
1. **Клонирование репозитория**
   ```bash
   git clone https://github.com/kirden31/TCA.git
   cd TCA
   ```
2. **Создание и настройка окружения**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate   # Linux/macOS
   # .venv\Scripts\activate    # Windows
   ```
3. **Установка зависимостей**
   ```bash
   pip install -r requirements/prod.txt
   ```
4. **Настройка параметров**
   Создайте файл `.env` в корне и укажите необходимые ключи (API‑ключи, пути к БД).
5. **Запуск приложения**
   ```bash
   cd src
   python3 -m main
   ```

## ⚙️ Конфигурация
- **.env** — переменные окружения.
- **src/config.py** — объектно‑ориентированный подход к конфигурации.
